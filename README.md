# 四轮足软件

整理日期：2026-11-08。三个独立PlatformIO工程，原工作目录工程保留；桌面副本与原工程不自动同步。

| 文件夹 | 用途 | 状态 |
|---|---|---|
| 01_ESP32_WheelFOC | 普通ESP32-WROOM-32E轮电机原始版 | 保留原参数/确认锁；不能直接套用S3引脚 |
| 02_ESP32S3_WheelFOC | 遥操手ESP32-S3轮电机，左右逐一测试 | 用户已完成四轮测试；整理时6V、7极对、校准1.5V |
| 03_ESP32S3_Servo | S3＋微雪Bus Servo Adapter(A)＋STS3032 | 新程序，需接线后实物验证 |

双击“四轮足软件.code-workspace”可同时查看三个工程。执行命令前检查终端当前文件夹；建议先单独打开正在调试的工程文件夹，任务菜单就不会选错。每个工程都有README接线及操作说明。

三个程序烧录到对应ESP32开发板，烧录新程序会替换板内原程序，不是同时运行三套程序。轮电机与舵机的接线不同，切换测试前先断电并拔掉上一套外设。新舵机程序使用GPIO17/18，不是轮电机的GPIO8/9。

## 共享工具

三个工程的命令/VS Code任务使用本目录`.tools/Scripts/python.exe`。在某个工程文件夹内用`& "..\.tools\Scripts\python.exe" -m platformio ...`，无需Activate.ps1。

经典ESP32版保留的是原始12.6V示例和未解锁状态，并未冒充最新S3实测配置；使用前按其README核对参数。S3轮电机已保留用户最新1.5V校准值。轮电机的V1与舵机的J 5是不同命令，不要混用。

## 开始舵机调试

打开03_ESP32S3_Servo/README.md，按GPIO17→微雪TX、GPIO18→微雪RX、GND共地接线，跳帽A，6V动力，S3原生USB连接电脑。首次只接一个STS3032。

在03工程内编译/烧录并打开115200控制台后：H → SCAN → I 1（实际ID）→ S → A → J 5 → J -5 → D。每条单独回车。A在当前位置使能，不自动回中；D/30秒超时会卸扭矩，先支撑机构。

舵机ID可以修改：只接一个舵机时使用ID 2 SINGLE等指令，并断电复查。AS5600的0x36地址固定，不能用这种方法改。


## 四轮＋四舵机整机基本运动

新增`04_ESP32_QuadrupedBasic`，面向物料清单里的两块普通ESP32-WROOM-32E（Micro-USB）。A控制前两轮和全部四舵机，B控制后两轮，UART连接。编号1左前、2右前、3左后、4右后，动力为6V。

先看该目录README完整接线和一根Micro-USB分次烧录步骤，之后双击目录内“打开控制面板.cmd”。需要先悬空校准、标定方向及舵机中位，再落地低速运动。新工程与前三个单项调试工程分别保留；整机仍需实物验证。
