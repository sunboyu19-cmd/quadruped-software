IMU 联动

单腿中位参考

等待联动固件反馈

使能后先到站趴中位，再固定参考腿、调整其余三腿。0° 使用 IMU 现有零点，不重设校准。X 正值左侧抬高；Y 正值抬头。目标暂限±5°。到达中位后可行驶，平稳行驶时继续调平。误差进入容差并稳定后，IMU 停止修正，舵机保持最后目标。调平期间锁定手动升降和单腿点动，完成后可手动操作；可用「暂停联动」提前结束。

DEBUG / WHEEL TEST

轮测试先四轮离地；先校准或使用已有校准启用。一次只测试一轮，松开即停。单腿调试在操作栏。
