SYNCHRONIZED POSTURE

四腿统一百分比

0% 趴下 / 100% 站立

按住 1 / 2：四腿升 / 降；3 / 4：前腿升 / 降；5 / 6：后腿升 / 降。每秒约3个百分点，松开保持最后目标。点击页面空白处使用快捷键，输入框内无效；升对应向站立点接近。

需四腿站趴点位有效且舵机已使能。滑动只选择目标，点击后统一执行；前腿=1/2，后腿=3/4，未选组保持最近目标；各腿按各自标定区间插值，共同进度、同步下发。支持与驾驶叠加，首次先停轮验证。
