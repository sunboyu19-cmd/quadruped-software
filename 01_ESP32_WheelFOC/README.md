# 单轮 FOC 台架测试

适用：经典 ESP32 DevKitC / WROOM-32E、AS5600 I²C编码器、2208/80T/100KV轮电机、支持3PWM的MiniFOC驱动板。
先只接一套电机和编码器，不接舵机、不测试整机平衡。

## 电源与接线

轮电机和编码器、ESP32三样还不足以驱动电机，必须有三相驱动板和动力电源。
现有M创MiniFOC V2/DRV8316商品标12–24V，尚未确认整板能否覆盖3S放电电压；不能因为芯片支持4.5V就默认整板支持6V或整个3S范围。
优先使用可限流台式电源做首次单轮测试，电压必须在整板明确允许范围内。3S电池只有在商家确认整板兼容后使用。
现有6V UBEC是舵机支路，本测试不使用。电机绝不能接ESP32的5V/3V3。

| ESP32或电源 | 对端 |
|---|---|
| GPIO25 | 驱动板IN1/PWM-A |
| GPIO26 | 驱动板IN2/PWM-B |
| GPIO27 | 驱动板IN3/PWM-C |
| GPIO13 | 已确认的高电平使能EN/nSLEEP |
| GND | 驱动板GND、电源负极、编码器GND共地 |
| 3V3 | AS5600模块的3.3V输入（核对模块原理图） |
| GPIO21 | AS5600 SDA |
| GPIO22 | AS5600 SCL |
| 动力电源正极→保险丝→开关 | 驱动板VM/VIN |
| 驱动板U/V/W | 电机三根相线 |

此表是接口功能映射，不是驱动板排针物理顺序。先按实物丝印/原理图核对，不能按位置猜。
DRV8316必须由板上硬件或配置选择3PWM模式；本程序没有SPI配置，不适合未经配置的6PWM板。
若板上没有可用EN/nSLEEP、使能极性不同、需要SPI初始化，需调整代码后再接动力电。
EN加约10kΩ下拉至GND，防止ESP32复位时悬空误使能（确认不与板载电路冲突）。
AS5600的SDA/SCL上拉到3.3V；模块已有合适上拉时不重复加。总线上只放一个地址0x36的AS5600。
径向/直径方向磁化的磁铁固定到电机轴，编码器固定到静止支架，磁铁中心正对芯片。
驱动旁保留已购470µF/25V母线电容，注意极性和短引线。

首次测试ESP32使用USB供电，动力只送驱动板；二者共地。不要同时接开发板外部5V和USB。
电机悬空并固定电机本体；校准时转子会动。物理开关/断电是紧急停机手段，校准期间串口指令会阻塞数秒。

## VS Code / PlatformIO

用VS Code打开本目录，安装官方PlatformIO IDE扩展。项目固定ESP32平台6.9.0（Arduino-ESP32 2.0.17）和SimpleFOC 2.3.3。SimpleFOC 2.3.4的ESP32后端需要Arduino-ESP32 3.x，不能直接混用本项目的2.x核心。

1. 默认环境`sensor_test`：先不接驱动动力，Build / Upload / Monitor（115200），手转电机。
2. 检查`a`角度随轴连续变化，`w`速度有正负；`mag=20`通常代表磁场有效，状态位含ML/MH或没有MD时先修正磁铁位置。
3. 查看`include/config.h`：确认实际驱动板3PWM、使能极性和电压范围；将`SUPPLY_VOLTAGE`改成驱动VM/GND实测值，确认后才把`DRIVER_WIRING_AND_POWER_CONFIRMED`改为`true`。
4. 电机极对数暂按原项目7配置（不是7极）。如果实物不同，需要修改；校准告警也需检查极对数。
5. 选择`motor_test`环境，Build / Upload，开串口监视器。接通合规动力电源后输入下表命令，每条按回车发送。

| 命令 | 行为 |
|---|---|
| `A` | 自动对齐/校准，再以零速待命；此时轮子会动 |
| `V1` | 1rad/s，约9.55rpm，低速正转 |
| `V-1` | 低速反转 |
| `V0` | 闭环零速保持，仍通电，不等于断电 |
| `D` | 关闭驱动，释放电机 |
| `K` | 延长10秒指令超时计时；持续测试需定期发送 |
| `S` / `H` | 查看状态 / 帮助 |

初始输出电压限幅1.5V、对齐1.0V、目标限幅±5rad/s。这是FOC电压指令限幅，不是电流限幅，也不是把母线稳压至1.5V。
`SUPPLY_VOLTAGE`必须描述真实母线，不得填6V来代替电压限幅；本版不自动测量/补偿电池电压。
若只抖动不转，先`D`并断动力电，检查编码器和磁铁同轴、三相接线、极对数、驱动3PWM配置及供电，再决定是否小幅提高对齐电压，不能直接照搬原项目6V对齐。

## 当前边界

实现为编码器闭环速度控制，底层电压模式FOC；未接电流采样，不是电流闭环。
AS5600连续健康检查失败、异常速度、可选nFAULT或10秒无控制命令时关闭驱动；这些软件检查不代替硬件限流/断电。
状态中的Uq是软件输出指令，不是电压表读数，也不表示已测量电流。
硬件未确认或未连接时，只能完成程序构建与编码器读数测试，不能宣称已经实机转动。

参考：[SimpleFOC AS5600](https://docs.simplefoc.com/magnetic_sensor_i2c)、[3PWM驱动](https://docs.simplefoc.com/bldcdriver3pwm)。


## 桌面整理版说明

本工程位于桌面“机器狗/四轮足程序”，三个工程共用上一级`.tools`，不需要激活虚拟环境。以`include/config.h`为实际编译配置；修改后需保存并重新烧录。此处是复制的独立工程，与原工作目录不会自动同步。
当前电脑的共享工具环境已准备好；换电脑时先安装Python，再在总目录执行`python -m venv .tools`和`.\.tools\Scripts\python.exe -m pip install platformio==6.1.18`。
