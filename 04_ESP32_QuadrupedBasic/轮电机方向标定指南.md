# 四轮方向标定与保存

轮子编号：1 左前、2 右前、3 左后、4 右后。四轮方向都保存在 A 板，B 板无需重复保存。方向保存与舵机站趴点位保存相互独立。

1. 更新 A 板固件，打开新版控制面板，连接 A 板。在“轮电机与方向”页查看四行当前方向、确认状态和已存方向。面板内容可通过右侧滚动条向下查看。
2. 支撑车身、四轮离地，点击“四轮悬空校准”，等两板都为 state=3。在低速下选轮、按住“单轮正转”，逐轮观察：正转应使轮子推动车身向前。记录需要反向的轮号，松开即停。
3. 点击“关闭轮驱动”。对应轮子当前正转正确则保持原方向，反了则将当前的 1 改为 -1 或 -1 改为 1。每轮都点击一次“应用并确认”，包括方向不需要改的轮子。这表示你已经实际确认该轮。舵机可以继续保持支撑，无需卸扭矩。
4. 点击“保存四轮方向”。必须看到 `WHEEL_SAVE ok=1 verified_readback=1`，四行显示“已保存”。四轮都确认时还会显示 `mask=F all_four_confirmed=1`。未应用的下拉框修改会阻止保存。
5. 重新上电 A 板、重新连接面板，点击“读取保存状态”核对四行。方向和确认状态自动恢复；上电不会自动使电机运动，需要重新悬空校准/使能。第一次保存后的实际断电检查需要在设备上完成。

“恢复已保存方向”会覆盖当前尚未保存的轮方向及下拉框修改，需要先关闭轮驱动。旧版本通过 SAVE 保存的轮方向也可以读取；再次保存后使用带校验的独立记录。

允许保存部分已确认的轮子，但未确认行仍会标记“尚未确认”，四轮全部确认前整车前进/后退/转向保持锁定。软件无法仅根据编码器判断车身前方，必须逐轮观察实际转向。

串口等效命令（每条回车）：

```text
DISARM
WDIR 1 1
WDIR 2 -1
WDIR 3 1
WDIR 4 -1
SAVEWHEELS
DIRSHOW
```

上面的正负号只是命令格式示例，必须按实际测试填写。`LOADWHEELS` 恢复已存四轮方向；`SAVE` 兼容保存轮和舵机两组方向；`TEACHSAVE` 保存舵机点位及舵机方向，不改轮方向。轮方向的设置、保存和恢复以及原有 SAVE 都需要先 DISARM；SDIR 设置还要求卸舵机扭矩。
