# 四舵机：限位、站趴示教和回中

编号：1左前、2右前、3左后、4右后。先关闭轮驱动，固定支撑车身。**不自动顶机械硬限位，不带连杆执行裸舵机大角度回中。**

## 更新与打开

关闭面板和6V动力，在04工程内更新A板（COM13按实际串口修改），B板不用更新：

```powershell
& "..\.tools\Scripts\python.exe" -m platformio run -e front_master -t upload --upload-port COM13
```

重开“打开控制面板.cmd”，连接A板。新增“限位／站趴标定／回中”页；若按钮提示未确认标定新版，说明A板仍未运行新固件。软件不自动开始标定或运动。

## 按顺序标定

1. **支撑车身 → 关闭轮驱动 → 卸全部扭矩**。卸扭矩会失去腿部支撑力，先托住车身。
2. 到标定页点击“读取限位/当前位置”。表格显示舵机内部数字限位、最近反馈、站立/趴下点、软件范围、方向和状态。内部限位0～4095不代表机械腿可以转满一圈。
3. 如果提示当前位置或端点接近零点，把所选腿摆在希望的机械中位、固定不动，勾选固定确认，再点击“所选原位设为2048”。这是写电子零偏，不是让已连接的腿转到旧坐标2048。会备份原零偏并清除该腿旧示教点；确认成功、断6V重启再读取验证。无法轻松摆到正确姿态时不要强扳或盲校准。
4. 在支撑下把四条腿摆成舒适的**站立姿态**，保持不动，勾选固定确认，点击“记录四腿：站立”。只读取位置，不发送运动目标。也可在表格/下拉框选某腿，单独记录该腿站立点。
5. 把四条腿摆成舒适的**趴下姿态**，保持不动，重新勾选固定确认，点击“记录四腿：趴下”。无需触碰机械极限。可以先用原点动功能摆位，但记录前要支撑、卸扭矩并保持姿态。
6. 两点都有效后，表格自动判断“＋1 到站立”或“－1 到站立”。含义是编码器计数增加/减少会向站立点移动，不是统一顺时针。自动填入SDIR；WDIR轮方向不变。
7. 点击“保存点位及方向”，存入A板NVS，断电保留。可以“导出标定记录”生成reports目录里的JSON副本。
8. 先读取确认四行都“可用”，当前姿态位于各自已教区间，再点击“舵机当前位置使能”。运动前解除妨碍关节转动的固定，保留车身托举；去“舵机点动与姿态”页，先应用少量站趴比例，低速验证路径无干涉，再用“缓慢到站立/趴下”。

所有按钮都是人工发起，站趴两点需要真实摆位。记录姿态时固定腿，运动时应允许关节自由活动，不能夹死关节后让电机硬顶。

## 限位和运动规则

- **内部限位**：只读取舵机寄存器9/11，不自动修改EEPROM限位。
- **软件范围**：站立、趴下两个已教位置之间，与内部限位同时约束。两点只是你确认过的位置，不代表已探测机械硬限位或验证中间全路径。
- 两点过近不能判方向；两点相差超过半圈时视为疑似跨零点/不适合直接插值，拒绝运动。端点近0/4095会提示回中，先重新安排电子/机械中位后重录。
- 校零、恢复零偏或执行裸舵机机械回中时，所选腿的旧记录自动失效并清除，必须重录；更换舵机、改ID、重新安装连杆后也应清记录重教。
- 完整有效示教后，J点动仍每次最多5°，总范围按该腿的站趴区间；未完成示教时保留原来的±15°小范围测试。POSE仍受±15°、单步5°和已教区间的共同约束。
- 站趴切换逐步下发目标，约100编码器计数/秒（约8.8°/秒），4关节依次写入。比例0是趴下、1是站立，是关节角线性插值，不是机身高度百分比或几何步态规划。
- 轮子运动时不接受姿态切换；姿态切换过程中也不接受轮运动。先停止或等待完成。
- STOP、Esc、关闭面板会停止继续推进姿态目标，并保持最后目标和舵机扭矩；软件停止不保证物理瞬时静止。RELAX才会卸扭矩，先支撑。
- 电脑面板每500ms发专用HB，姿态运动2秒没收到主控输入即暂停；HB不刷新轮运动租约，轮仍遵守原按住续发和1.5秒停轮规则。反馈异常、越界、跟随误差过大或45秒超时也停止推进，须检查负载/供电/机构。
- 新增页带滚动条，顶部命令框始终保留。页签和日志之间的分隔条可以拖动，调整两部分高度。日志默认隐藏周期数据，表格仍更新；“读取限位”获取新反馈，“查看已存点位”可能显示较旧缓存，注意状态提示。

## 对应命令

| 命令 | 功能 |
|---|---|
| LIMITS | 轮关闭时读取四舵机内部限位、零偏和反馈 |
| TEACHSHOW | 显示已记录点位及缓存状态，无运动 |
| TEACH STAND / TEACH LIE | 固定支撑、轮与舵机扭矩关闭时记录四腿 |
| TEACH STAND 2 / TEACH LIE 2 | 单独记录2号某个点 |
| TEACHSAVE | 轮关闭时保存点位和方向到A板 |
| TEACHCLEAR 2 / TEACHCLEAR ALL | 轮和舵机关闭时清除所选/全部记录 |
| SETMID 2 FIXED | 固定期望机械中位后原位校零，清2号旧点位 |
| POSTURE STAND / POSTURE LIE | 已使能、四组记录有效时缓慢切换 |
| BLEND 0.25 | 站趴比例25%，0趴下、1站立 |
| HB | 仅刷新姿态控制的主机心跳，不维持轮运动 |
| STOP | 停轮并暂停姿态推进，保留舵机扭矩 |

优先使用面板操作；串口单独控制姿态时也需要在2秒内续发HB，否则会暂停。新增功能交付时仅做程序编译和软件检查，需要按以上流程实物示教验证。
